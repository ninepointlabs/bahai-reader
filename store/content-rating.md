# Content rating: IARC questionnaire (draft answers)

Both Google Play (App content → Content rating) and Microsoft Partner Center (Age ratings) use the IARC questionnaire.
The exact questions change from time to time; these are the likely answers for what the app is. Answer each from
what is in the app, not from these notes, if the wording differs.

**Category**: "Reference, News, or Educational" (a reader of prayers and scripture). Not a game, not social or
communication, not entertainment.

| Topic | Answer | Notes |
|---|---|---|
| Violence, blood, gore | No | The texts are scripture and history (e.g. God Passes By describes persecution of early believers in words). There are no images or depictions; IARC asks about depicted content. If a question asks specifically about written references, answer honestly that historical texts mention martyrdom in narrative text, with no graphic detail and no imagery. |
| Fear / horror | No | |
| Sexual content, nudity | No | |
| Profanity / crude humour | No | |
| Controlled substances (drugs, alcohol, tobacco) | No depiction or encouragement | The Kitáb-i-Aqdas and other texts forbid alcohol and drugs; that is a reference that discourages use, not a depiction. If asked about "references", answer per the question's own definition. |
| Gambling (real or simulated) | No | |
| Discrimination / hate | No | |
| Users can interact or exchange content with each other | No | No accounts, chat, comments, sharing feeds or user-generated content visible to others. Notes stay on the device unless the person exports them or syncs them between their own devices through a folder they choose; nothing is shown to anyone else. |
| Shares the user's location with other users | No | Location is used on the device only, and the Android app has no network access. |
| Digital purchases | No | Free, no in-app purchases. |
| Unrestricted internet access (e.g. a web browser) | No | The Windows and Linux apps only fetch language packs from bahaiprayers.net when asked. The Android app has no network access. |
| Ads | No | |
| Is the app a "religious" app? | (Not an IARC question) | IARC rates content, not subject. Religious content alone does not raise the rating. |

**Expected result**: Everyone / ESRB Everyone, PEGI 3, USK 0, ClassInd L (Brazil), Australia G, IARC 3+.

If the result comes back higher than expected, the likely cause is a "references to violence" or "references to
alcohol" answer; re-read that question's own definition before appealing.

**Audience**: the app is not directed at children (see the target audience note in
[google-play-data-safety.md](google-play-data-safety.md)). A low content rating does not mean the app targets children;
the two are separate questions in Play Console.
